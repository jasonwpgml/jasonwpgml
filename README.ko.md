# Jason

### 로컬에서 돌아가는 AI 시스템을 만드는 풀스택 개발자입니다.

AI에 들어가는 기술 스택은 모두 다뤄봤습니다. 데이터 수집과 저장부터
검색 시스템과 LLM 파이프라인, 이를 서비스하는 백엔드, 사용자가 직접 보는 화면까지
전부 만들 수 있습니다.

지금은 개인용 AI 에이전트와 LLM 위키를 만들고 있습니다. 여러 에이전트가 맥락을 주고받으며
역할을 나눠 일하는 방식, 코딩 에이전트가 코드베이스를 더 쉽게 이해하고 수정할 수 있는
개발 방식도 연구하고 있습니다.

개인 데이터와 AI 대화를 오래 보관하고 필요할 때 다시 꺼내 쓸 수 있도록, 원본 기록부터
이벤트 저장소, 장기 기억, 검색 인덱스까지 데이터를 어떻게 나누어 저장할지도 깊이
파고들고 있습니다. 새로운 기술을 시험하는 데서 그치지 않고 실제로 쓰는 제품까지
만드는 일을 좋아합니다. 여기 있는 프로젝트도 대부분 제가 필요해서 만들기 시작한 것들입니다.

## 계속 궁금한 것

- 개인용 AI 에이전트와 LLM 위키를 만들어 활동과 대화를 오래 쓸 수 있는 지식으로 남기는 방법
- 여러 에이전트가 맥락을 주고받고, 역할을 나누고, 작업을 자연스럽게 이어받는 방법
- 코딩 에이전트가 코드베이스를 빠르게 이해하고 안전하게 수정·검증할 수 있는 개발 방식
- 원본 기록, 이벤트 저장소, 장기 기억, 검색 인덱스, 데이터 계보를 어떻게 나누어 저장할지
- 데이터 저장부터 사용자 화면까지 이어지는 풀스택 제품 개발
