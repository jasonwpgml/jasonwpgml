# Jason

### AI 시스템을 만듭니다. 되도록 로컬에서 도는 쪽으로요.

AI 제품이라면 아래에서 위까지 다 건드리는 편입니다. 바닥의 데이터, 그 위의 검색과 LLM
파이프라인, 그걸 물어다 주는 백엔드, 그리고 결국 누군가 눌러야 하는 화면까지요. 그중에서
자꾸 다시 붙잡게 되는 건 마지막입니다. 아무도 두 번은 안 여는 파이프라인은 그냥 비싼
크론잡이니까요.

여기 있는 것들 대부분은 제가 쓰려고 만들기 시작했다가 일이 커진 경우입니다.

## 계속 붙잡고 있는 주제

- AI 시스템을 로컬에 두는 것, 그리고 거기 쌓인 지식을 오래 살려두는 것
- 에이전트를 어떻게 짜고, 어떻게 굴리고, 잘 돌아가는지 어떻게 확인할지
- 검색 쪽 배관 일체: 파이프라인, 임베딩, 벡터 DB, RAG
- 레포가 아니라 제품을 보면서 하는 풀스택 개발
