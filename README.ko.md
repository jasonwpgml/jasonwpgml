# Jason

### 사람과 에이전트가 같이 일하는 법을 만듭니다. 새로 나온 건 일단 써 보는 편이라 가끔 데기도 합니다.

요즘은 거의 AI 에이전트만 붙잡고 있습니다. 새 모델이나 에이전트 도구가 나오면
그걸로 뭔가 만들어 보고, 어디서 깨지는지 확인합니다.

지금은 개인용 AI 에이전트와 LLM 위키를 만들고 있습니다. 팀 프로젝트에서는 AI가
상황을 이해하고 최종 판정은 코드가 맡는 구조로 서비스를 만들었습니다.

여러 에이전트가 맥락을 주고받으며 역할을 나눠 일하는 방식, 코딩 에이전트가 코드베이스를
더 쉽게 이해하고 수정할 수 있는 개발 방식도 연구하고 있습니다. 에이전트 하나에서 얻은
결과만으로는 판단하기 어려워서 여러 에이전트에서 직접 측정합니다.

머신러닝·딥러닝 자격증 강의에도 출강하고 있습니다. 제가 데어 가며 배운 걸 수강생들은
덜 고생하고 배웠으면 합니다.

여기 있는 프로젝트도 대부분 제가 필요해서 만들기 시작한 것들입니다.

포트폴리오 2026년 판: [jasonwpgml.github.io](https://jasonwpgml.github.io)

## 계속 궁금한 것

- 여러 에이전트가 맥락을 주고받고, 역할을 나누고, 작업을 자연스럽게 이어받는 방법
- 코딩 에이전트가 코드베이스를 빠르게 이해하고 안전하게 수정·검증할 수 있는 개발 방식
- 개인용 AI 에이전트와 LLM 위키를 만들어 활동과 대화를 오래 쓸 수 있는 지식으로 남기는 방법
- 에이전트의 기억을 원본 기록, 이벤트 저장소, 검색 인덱스, 데이터 계보로 어떻게 나누어 저장하고, 어디까지 로컬에 둘지
- 매달 새로 나오는 모델과 에이전트 도구, MCP 같은 프로토콜 중에서 써 보고 나서도 계속 쓰게 되는 것
