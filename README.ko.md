# Jason

### 로컬 우선 지식 시스템, 에이전트 워크플로, 쓸모 있는 제품을 만드는 AI 시스템 빌더.

데이터 계층부터 인터페이스까지 실용적인 AI 소프트웨어를 만듭니다. 검색·LLM 파이프라인,
안정적인 백엔드 서비스, 그리고 실제 사용자가 쓸 수 있는 워크플로를 연결합니다.
