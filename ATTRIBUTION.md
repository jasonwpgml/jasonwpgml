# Attribution Guide · 출처 표시 안내

**EN** — Everything original in this repo is free to reuse and adapt under
[CC BY 4.0](./LICENSE). The one condition is legally binding: **keep a visible
credit that says your work is based on this repository.** Pick any format below.

**KO** — 이 저장소의 원본 콘텐츠는 [CC BY 4.0](./LICENSE)에 따라 자유롭게 사용하고
고쳐 쓸 수 있습니다. 조건은 하나이고, 라이선스상 의무입니다. **이 저장소를 참고했다는
표시를 보이는 곳에 남겨 주세요.** 아래 형식 중 아무거나 쓰면 됩니다.

## Copy-paste formats · 그대로 복사해 쓰는 형식

**Markdown (README footer):**

```markdown
> Based on [jasonwpgml/jasonwpgml](https://github.com/jasonwpgml/jasonwpgml)
> by Jason, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
```

**Plain text (comments, docs, commit messages):**

```text
Based on jasonwpgml/jasonwpgml by Jason
(https://github.com/jasonwpgml/jasonwpgml), CC BY 4.0.
```

**HTML comment (invisible watermark — fine as an *extra*, not a substitute
for a visible credit):**

```html
<!-- Derived from https://github.com/jasonwpgml/jasonwpgml (Jason, CC BY 4.0) -->
```

**Badge:**

```markdown
[![Based on jasonwpgml](https://img.shields.io/badge/based%20on-jasonwpgml%2Fjasonwpgml-1f6feb)](https://github.com/jasonwpgml/jasonwpgml)
```

**BibTeX** — GitHub's "Cite this repository" button on the repo page generates
one from [`CITATION.cff`](./CITATION.cff).

## What counts as "using" · 어디까지가 "사용"인가

Attribution is required when you copy or adapt the README structure or prose,
the SVG illustrations, the banner assets, or the agent-profile format — in
whole or in part. A fork that keeps the `LICENSE` and `NOTICE` files already
satisfies this. Ideas alone (e.g. "a README for AI agents") are not
copyrightable, but a credit is still appreciated.

README의 구성이나 문장, SVG 일러스트, 배너, 에이전트 프로필 포맷을 일부라도
복사·변형해 쓰면 출처 표시 대상입니다. `LICENSE`와 `NOTICE` 파일을 유지한 포크는
그 자체로 조건을 충족합니다. 아이디어 자체(예: "AI 에이전트용 README")는 저작권
대상이 아니지만, 그래도 크레딧을 남겨 주면 감사하겠습니다.
